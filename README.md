# Daily Reminder Scheduler

A minimal Java console project to add, view, and manage reminders.  
Reminders are stored in a file for persistence, so they are saved even after the program is closed.

---
## Features

- Add reminders with a date
- View today's reminders
- View all reminders
- Mark reminders as done
- Reminders persist in `reminders.txt`
- Easy-to-understand console menu
- Input validation and error handling
